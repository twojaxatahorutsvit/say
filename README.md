# КСБУ — hero prototype

Імерсивний hero-екран із відео, прив'язаним до прокручування сторінки.

## Важливо

- Проєкт не має локальних залежностей.
- Нічого не потрібно встановлювати через npm.
- Оригінальне відео в корені папки не змінене.
- Для сайту використовується копія `assets/nvg-lowering.mp4`.

## Публікація через GitHub і Vercel

1. Створити порожній репозиторій на GitHub.
2. Завантажити в нього вміст цієї папки.
3. У Vercel натиснути **New Project** та вибрати GitHub-репозиторій.
4. Вибрати **Framework Preset: Other**.
5. Не вказувати Build Command.
6. Натиснути **Deploy**.

Vercel опублікує статичні файли без локального встановлення бібліотек.
